4 Step 2 — Write Student.java (Bean Class) ▾
"First we create the Bean class. This is just a normal Java class — nothing Spring-specific here. We have private fields, getter and setter methods, and a display method."
src/demo/Student.java
package demo; public class Student { // Step 1: private fields private String name; private String address; // Step 2: getter for name public String getName() { return name; } // Step 3: setter for name public void setName(String name) { this.name = name; } // Step 4: getter for address public String getAddress() { return address; } // Step 5: setter for address public void setAddress(String address) { this.address = address; } // Step 6: method to display details public void showdetails() { System.out.println("Name = " + name); System.out.println("Address = " + address); } }

Explain line by line to students

→package demo — this class belongs to demo package
→private String name — field is private, cannot access directly from outside
→getName() — getter returns the value of name
→setName() — setter sets the value into name — Spring uses this to inject values
→showdetails() — just prints the values so we can see output
Ask students: "Why do we need setters?" — Answer: Because Spring uses setter injection to put values into the fields. Without setters, Spring cannot inject.
5 Step 3 — Write applicationContext.xml ▾
"This is the most important file in Spring. This XML file tells Spring — what class to create, what name to give it, and what values to put inside it. Spring reads this file and creates our beans."

How to create XML file in Eclipse

1
Right click on src folder → New → File
2
File name: applicationContext.xml → Click Finish
src/applicationContext.xml
<?xml version="1.0" encoding="UTF-8"?> <beans xmlns="http://www.springframework.org/schema/beans" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd"> <!-- Bean 1: Student with name Rahul --> <bean id="s1" class="demo.Student"> <property name="name" value="Rahul" /> <property name="address" value="Pune" /> </bean> <!-- Bean 2: Another Student --> <bean id="s2" class="demo.Student"> <property name="name" value="Priya" /> <property name="address" value="Mumbai" /> </bean> </beans>

Explain every tag line by line

Tag / Attribute What it means
<beans> Root tag — all bean definitions go inside this
xmlns XML namespace — tells which Spring schema to use (just copy paste always)
<bean> Defines one Spring bean — one Java object
id="s1" Unique name for this bean — used to get it later in Java code
class="demo.Student" Full class name with package — Spring creates object of this class
<property> Injects value into a field using setter method
name="name" Field name in Student class — Spring calls setName()
value="Rahul" Value to inject — Spring calls setName("Rahul")
Common mistake: class attribute must have full package path. Writing only "Student" instead of "demo.Student" will give ClassNotFoundException error.
6 Step 4 — Write Test.java (Main Class) ▾
"Now we write the main class. This is where we start the Spring container, get our bean from it, and call the method. This is always 3 lines of work — load container, get bean, use bean."
src/demo/Test.java
package demo; import org.springframework.context.ApplicationContext; import org.springframework.context.support.ClassPathXmlApplicationContext; public class Test { public static void main(String[] args) { // Step 1: Load Spring container — reads applicationContext.xml ApplicationContext context = new ClassPathXmlApplicationContext("applicationContext.xml"); // Step 2: Get bean s1 from container Student s1 = (Student) context.getBean("s1"); // Step 3: Use the bean — call showdetails() s1.showdetails(); // Get second bean s2 Student s2 = (Student) context.getBean("s2"); s2.showdetails(); } }

Explain line by line

→ApplicationContext context — creates the Spring container and loads XML file
→ClassPathXmlApplicationContext — looks for XML in src folder (classpath)
→context.getBean("s1") — gets the bean with id "s1" from container
→(Student) — type casting because getBean returns Object type
→s1.showdetails() — calls the method on our bean
Ask students: "Did we write Student s1 = new Student() anywhere?" — Answer: No! Spring created it. That is IoC in action.

2

3

4
context.getBean("s1") returned that Student object to us
5
We called showdetails() → it printed Name and Address
8 Common Errors and Fixes ▾
"Let me tell you the most common mistakes students make. If you see these errors, check these things first."
Error Reason Fix
ClassNotFoundException: demo.Student Wrong class name in XML Check class="demo.Student" — package must match exactly
FileNotFoundException: applicationContext.xml XML not in src folder Make sure XML is directly inside src — not inside package
NoSuchBeanDefinitionException: s1 Wrong bean id in getBean() Check id in XML matches getBean("s1") exactly
NullPointerException Property name mismatch name in XML property must match setter method name exactly
JARs not found error JARs not added to build path Right click JARs → Build Path → Add to Build Path
Most common mistake: writing class="Student" instead of class="demo.Student" in XML. Always include the full package name.
