2 Why Inject Collections? ▾
"In real applications a student does not just have a name and address. A student has multiple skills, belongs to multiple departments, and has multiple books to study. We cannot store multiple values in a single String. We need List, Set and Map. Spring supports injecting all these collection types."
List
Ordered collection
Allows duplicate values
Example: List of skills
[HTML, CSS, Java, Java]
XML tag: <list>
Set
Unordered collection
NO duplicate values
Example: Set of departments
{CS, IT, ENTC}
XML tag: <set>
Map
Key-Value pairs
Each key is unique
Example: Books map
{Java: Prof.Mehta}
XML tag: <map>
What We Are Building Today
A Student bean with 5 fields: id (int), name (String), skills (List), departments (Set), books (Map). We will inject all 5 fields using Constructor Injection. This is a complete real-world style bean with multiple data types.
3 File 1 — Student.java with Collections ▾
"First let us write the Student class. We will have 5 fields — int, String, List, Set and Map. We need a constructor that accepts all 5 fields. Spring will call this constructor to inject everything."
src/demo/Student.java
package demo; import java.util.*; public class Student { // Field 1 — simple int private int id; // Field 2 — simple String private String name; // Field 3 — List of skills (allows duplicates, ordered) private List<String> skills; // Field 4 — Set of departments (no duplicates, unordered) private Set<String> departments; // Field 5 — Map of books (key=subject, value=professor name) private Map<String, String> books; // DEFAULT CONSTRUCTOR public Student() { System.out.println("Default Constructor"); } // CONSTRUCTOR FOR id ONLY public Student(int id) { this.id = id; } // CONSTRUCTOR FOR name ONLY public Student(String name) { this.name = name; } // CONSTRUCTOR FOR List (skills) public Student(List<String> skills) { this.skills = skills; } // CONSTRUCTOR FOR Set (departments) public Student(Set<String> departments) { this.departments = departments; } // CONSTRUCTOR FOR Map (books) public Student(Map<String, String> books) { this.books = books; } // MAIN CONSTRUCTOR — accepts ALL 5 fields // Spring calls this when all 5 constructor-args given in XML public Student(int id, String name, List<String> skills, Set<String> departments, Map<String, String> books) { this.id = id; this.name = name; this.skills = skills; this.departments = departments; this.books = books; } // viewdetails method — prints all fields public void viewdetails() { System.out.println("Id = " + id); System.out.println("Name = " + name); // Print List using Iterator System.out.println("Skills:"); Iterator<String> it = skills.iterator(); while(it.hasNext()) { System.out.println(" " + it.next()); } // Print Set using Iterator System.out.println("Departments:"); Iterator<String> it1 = departments.iterator(); while(it1.hasNext()) { System.out.println(" " + it1.next()); } // Print Map using Entry Set Iterator System.out.println("Books:"); Iterator<Map.Entry<String, String>> it2 = books.entrySet().iterator(); while(it2.hasNext()) { Map.Entry<String, String> entry = it2.next(); System.out.println(" " + entry.getKey() + " : " + entry.getValue()); } } }

Explain These Points to Students

Code Explanation
import java.util.* Imports all collection classes — List, Set, Map, Iterator
List<String> skills List that holds String values — skills of student
Set<String> departments Set that holds String values — no duplicates allowed
Map<String,String> books Map with String key (subject) and String value (professor)
Multiple constructors Spring picks the right constructor based on how many constructor-arg tags we give in XML
Iterator Used to loop through List, Set and Map and print each element
entry.getKey() Gets the key from Map entry (subject name)
entry.getValue() Gets the value from Map entry (professor name)
Ask students: "Why do we have multiple constructors?" — Answer: Spring picks the matching constructor based on the number and types of constructor-arg values in XML. One constructor for each use case.
4 File 2 — applicationContext.xml with All 3 Collections ▾
"Now we write the XML. This is the most important part of today's class. We will write 4 beans — one with all 5 fields, one with only List, one with only Set, one with only Map. This shows students how flexible Spring injection is."
src/applicationContext.xml — Full Configuration
<?xml version="1.0" encoding="UTF-8"?> <beans xmlns="http://www.springframework.org/schema/beans" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd"> <!-- ========================================== BEAN s1 — ALL 5 FIELDS injected Uses main constructor with 5 parameters =========================================== --> <bean id="s1" class="demo.Student"> <!-- constructor-arg 1 — int id --> <constructor-arg value="10" /> <!-- constructor-arg 2 — String name --> <constructor-arg value="Rahul" /> <!-- constructor-arg 3 — List of skills --> <constructor-arg> <list> <value>HTML</value> <value>CSS</value> <value>Java</value> <value>Spring Framework</value> </list> </constructor-arg> <!-- constructor-arg 4 — Set of departments --> <constructor-arg> <set> <value>CS</value> <value>IT</value> <value>ENTC</value> <value>MECH</value> </set> </constructor-arg> <!-- constructor-arg 5 — Map of books --> <!-- key = subject name, value = professor name --> <constructor-arg> <map> <entry key="Java" value="Prof. Mehta" /> <entry key="Python" value="Prof. Shah" /> <entry key="DBMS" value="Prof. Patil" /> <entry key="Spring" value="Prof. Rao" /> </map> </constructor-arg> </bean> </beans>

Every New XML Tag Explained

XML Tag Purpose Collection Type
<list> Injects a List — ordered, allows duplicates List<String>
<set> Injects a Set — unordered, no duplicates Set<String>
<map> Injects a Map — key-value pairs Map<String,String>
<value> One item inside list or set String value
<entry key="" value=""> One key-value pair inside map Map entry
<constructor-arg> without value attribute Used when injecting a collection — collection tag goes inside List / Set / Map
<constructor-arg value=""> Used when injecting simple value like String or int String / int
Important: When injecting simple value like String or int — use value attribute directly in constructor-arg tag. When injecting collection — do NOT use value attribute. Instead put list/set/map tag INSIDE constructor-arg tag.

Point List Set Map
Data stored Single values Single values Key-Value pairs
Duplicates Allowed Not allowed Keys unique, values can repeat
Order Ordered (insertion order) Unordered No guaranteed order
XML tag in Spring <list> <set> <map>
Item tag <value> <value> <entry key="" value="">
